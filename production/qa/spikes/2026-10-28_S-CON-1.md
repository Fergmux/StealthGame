# Spike S-CON-1: owner-side warp mechanism, 2026-10-28

> **Story:** `production/epics/concealment-bushes/story-010-spike-s-con-1-owner-side-warp.md` (TR-con-004; GDD AC-CON-31, OQ8)
> **Governs:** ADR-0017 §4 (owner smoothness; order of trial a1, b, a2) · **Engine:** UE 5.8.4 Development editor, in-process CQTest PIE (listen host + 1 client), `-nullrhi`, legacy `IpNetDriver`
> **Verdict:** **(b) PredictOnPress — PASS.** Over 100 hides and 100 exits under StealthLeak2 every transition started moving the owner within 11.7 ms of the press (p95 9.3 ms; the first owner frame after the press) and no correction was applied during any transition (0 of 200; end gap 0.0 cm), with the server reaching the state every time. (a1) OnStateArrival FAILS AC-CON-31: press-to-motion is one round trip (p50 ~242 ms) and every transition takes corrections > 5 cm (E4: the owner-started source is duplicated, then corrected). (a2) not built (it cannot start earlier than (a1)). ADR-0017 is not edited by this spike; §4 is amended through the ADR route (below).

## The rig

`Source/StealthTestHarness/Private/Tests/PIE/Spikes/ConcealmentOwnerWarpSpike.cpp` (`StealthSpike.Concealment.ConcealmentOwnerWarp.MeasureEveryMechanism`; named `StealthSpike.*` so it never runs in the per-commit `^StealthGame.` gate). One remote client's owner hides in an L_Prototype bush and leaves it, over and over, through the **production path**: `UPawnCommandClient::PressHide` (the Hide input's handler) → the reliable `ServerPawnCommand` → Round's resolution queue → `UConcealmentService` → the server's one `FRootMotionSource_MoveToForce` (`ConcealEnter` / `ConcealExit`, fixed target, the same server source for NPC and player pawns). Packet simulation **StealthLeak2** (PktLag 100 ms, PktLoss 2 %, ADR-0008's `LeakNetProfile`) on every driver; the re-entry cooldown is lifted for the session (test seam) so cycles run back to back; no crowd. Each mechanism runs **100 hides and 100 exits** (the baseline 20 + 20):

| Mode | Mechanism (ADR-0017 §4) | Owner side | Server side |
|---|---|---|---|
| 0 | ServerOnly (baseline) | follows the server's corrections | the source only |
| 1 | **(a1)** OnStateArrival | starts the identical source (same `InstanceName`, parameters, fixed target) when its replicated `FActionState` (BushEnter / BushExit) arrives, seeked to `ServerNow − Start` | the source only |
| 2 | **(b)** PredictOnPress | starts the identical source at the press; `bClientIgnoreMovementCorrections` for the transition + one RTT | `bIgnoreClientMovementErrorChecksAndCorrection` for the transition + one RTT; then one normal correction to the fixed end point; `bServerAcceptClientAuthoritativePosition` stays false |

(a2), the owner-only start message, was not built: ADR-0017 tries it last because it is a new owner wire element (IVP allowlist row), and it can only be as early as (a1) plus nothing — its press-to-motion is the same round trip (a2 needs the server's execution time, which is what `FActionState` carries).

Per transition the owner records: **press-to-motion** — wall clock from the press to the first owner frame ≥ 1 cm from the press position (the story's definition); every **applied correction** during the observation window (1.6 s: the 0.9 s transition + RTT + margin; count and the largest |server − owner| displacement at application — a correction the owner ignores is never applied, so it shows on no frame); the **end gap** between the owner and the server copy; and whether the server reached the state. Records: `production/qa/spikes/2026-10-28_S-CON-1/scon1-leak2.jsonl` (one line per transition).

Reproduce: `powershell -File tools/dev/cycle.ps1 -NoLaunch` then
`UnrealEditor-Cmd StealthGame.uproject -ExecCmds="Automation RunTests StealthSpike.Concealment; Quit" -unattended -nullrhi -SCON1Profile=StealthLeak2` (≈ 16 min; `-SCON1Profile=StealthLeak1` for 1 % loss).

**Rig history (kept honest):** the first run (StealthLeak1) stood the owner 65 cm from the planter edge, outside `BushEntryReachCm` 60: every Hide(Enter) was refused `OutOfReach`, so no hide moved (the exits trivially "reached Outside"). Fixed to 40 cm (the PIE tests' entry) and re-run; a second run was aborted 10 min in when an MCP probe reached the commandlet's MCP server and its error log failed the test. The numbers below are the third run.

## E4 (duplicate-source behaviour) - observed

An owner-started `FRootMotionSource_MoveToForce` with the same `InstanceName` as the server's, started when the replicated
`FActionState` arrives (a1), is **not merged** with the server's: the owner runs its own copy a round trip late, the server's
corrections (`ClientAdjustRootMotionSourcePosition` -> `ClientAdjustPosition`) keep arriving for the moves the owner had already
simulated without the source, and the owner is corrected on every transition (100 of 100 hides, 100 of 100 exits above 5 cm).
That is the "duplicated, then corrected" branch of E4. (b) avoids it by starting the source at the press - before any server
move of the transition exists - and suppressing correction generation (server) and application (owner) for the transition
plus one round trip.

## Verdict and consequences

- **Mechanism (b) PredictOnPress** is chosen, in ADR-0017 §4's order of trial (a1 tried first and failed, b passed, a2 not
  needed). Production default: `Stealth.Concealment.OwnerWarp` = 2 (`UConcealmentComponent::OnOwnerHidePressed` /
  `OnServerWarpStarted`). The recorded values for story con-012 AC2 are the flags and the window: owner
  `bClientIgnoreMovementCorrections` and server `bIgnoreClientMovementErrorChecksAndCorrection` for `BushEnterSwapSec` /
  `BushExitDurSec` + one RTT (the owner's ping, clamped 50-800 ms), then one normal correction to the fixed end point;
  `bServerAcceptClientAuthoritativePosition` stays false. Recorded in ADR-0017 as amendment "S-CON-1 resolution 2026-10-28".
- Known cost (recorded on story 012): when the server refuses a Hide the owner judged legal (e.g. a cooldown the owner did not
  model), the owner's predicted warp is undone by the one normal correction after the window - a visible snap on a refused
  hide only. The owner's own legality check (`FindEnterableBush`, reach and open side) keeps this rare.
- Story con-012 is unblocked and implemented: `StealthGame.Concealment.PIE.OwnerWarpNoSnap` (20 + 20 transitions under
  StealthLeak2 in the per-commit gate) passes with worst press-to-motion 10.3 ms and 0.00 cm worst correction.
