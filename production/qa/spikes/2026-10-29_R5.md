# Spike R5: hidden-primitive leaks on 5.8.4, 2026-10-29

> **Story:** `production/epics/concealment-bushes/story-021-spike-r5-hidden-primitive-leaks.md` (TR-con-006; GDD CON-R6b, AC-CON-23 preview)
> **Governs:** ADR-0017 §6 (`SetVisibility(false, true)` with the three gating flags on class defaults), Verification Required R5 · **Engine:** UE 5.8.4 Development editor, rendering PIE (standalone, 1 player), L_Prototype, D3D12 SM6, Lumen software tracing, the project's `r.RayTracing=False`
> **Verdict:** **PASS for the cells this build can run (software Lumen x VSM on/off x low sun / noon / shade): the ADR-0017 §6 flag set suffices, including for groom and attached Niagara — no extra step.** Every hidden primitive (body mesh, groom, Niagara, all attachments) has no render proxy in the Hidden state of every cell, and inside the subject's region the Hidden-vs-Empty difference equals the Empty-vs-Empty noise (mean 0.21-0.24 vs 0.21-0.25 luma levels; the visible control 17.9-19.4). **NOT RUN: the hardware-RT Lumen cells** (`r.RayTracing=False` in this project; they need an RT build - carried to story 034's leak matrix). Hide/show cost: the `SetVisibility` pair costs 0.024 ms of game thread (0.016 ms under the D56 min-spec PROXY affinity); the render-thread cost of the proxy rebuild was not measurable in editor PIE (`GRenderThreadTime` reads 0 there).

## The rig

Throwaway console command `Stealth.Spike.R5 [SettleFrames]` (`Source/StealthGame/Private/Spikes/ConcealmentR5Spike.cpp`, non-Shipping), run in the editor's PIE through the Unreal MCP (`StealthPlayToolset.RunPlayConsoleCommand`). It follows the production rule shape: the subject is the game's configured character class (`UStealthSettings::CharacterClass`), hidden exactly as `UConcealmentComponent::ApplyHidden` does — `SetVisibility(false, /*propagate*/ true)` on the mesh — with the three gating flags left at their class defaults (pinned false on `AStealthPawn`'s mesh and capsule by this batch and audited by `StealthGame.Pawn.RenderFlagParity`), never `bHidden`. Attached to the subject for the unverified cases: a **groom** component (the MetaHuman Kellan `Hair_S_360Waves` groom, on the `head` socket) and a **Niagara** component (engine template `FountainLightweight`, 1.2 m up, active). The subject stands on open ground 7 m ahead of the local player's own camera (the sample's camera system owns the view target, so the spike keeps it; the player's own pawn is frozen and its mesh hidden so the view holds still), framing it and the ground its shadow falls on. NpcCount was set to 0 for the session (no crowd moving through the frame; DefaultGame.ini restored after) and the HUD was hidden (`showhud`).

Matrix (6 cells): sun **low** (pitch −10°), **noon** (−80°), **shade** (−55° under a 6 × 6 m roof slab 4 m above the spot) × **VSM on / off** (`r.Shadow.Virtual.Enable`). Lumen **software** tracing only: hardware-RT Lumen needs `r.RayTracing=True`, a read-only project setting (ADR-0022 keeps it off), so the four HW-RT cells cannot run in this build — recorded as NOT RUN, not as PASS. Per cell, four states in order **EmptyA** (subject 200 m away), **Visible**, **Hidden**, **EmptyB**; each settles 90 frames (the run used `Stealth.Spike.R5 90`; the editor PIE ran at ~3 fps, so 30 s per state) (VSM page invalidation and Lumen's temporal accumulation converge) and is captured as six screenshots 4 frames apart (`FScreenshotRequest`, the PIE viewport). Per state the rig also logs every subject primitive's visibility and **whether it still has a render proxy** (`SceneProxy`) — the engine-level fact the pixels confirm. Then a **profile**: 120 frames static, then 120 frames toggling hide/show every frame (game-thread cost of the `SetVisibility` pair; render-thread and game-thread frame times, `GRenderThreadTime` / `GGameThreadTime`).

Analysis: `tools/analysis/r5_diff.py` (observations only): the temporal mean of each state's six frames; **noise floor** = the 99th percentile of |EmptyA − EmptyB| (luma-weighted RGB distance); **hidden residual** = |Hidden − EmptyA| (p99, max, pixels above the floor); **visible control** = |Visible − EmptyA| (must be large). A heat image `<cell>_diff_hidden_x8.png` per cell. The ADR's "two empty bushes at matched sway phase" floor is replaced by the same empty spot captured twice (the prototype bushes are static meshes with no sway); the magenta occlusion proxy was not used (the diff against the empty frame shows any residual directly).

## Results

### Render proxies (engine-level)

In every cell: EmptyA / Visible / EmptyB — `CharacterMesh0`, `R5Groom` (GroomComponent) and `R5Niagara` (NiagaraComponent)
each have a proxy; **Hidden — no primitive of the subject has a proxy** (`r5.jsonl`, `"state":"Hidden","primitives"`). The
three gating flags read false on every subject primitive, and the world's `bCreateRenderStateForHiddenComponentsWithCollsion`
is 0. A primitive with no proxy cannot cast a shadow, write a VSM page, feed Lumen's surface cache or appear in a reflection,
which is what the pixels below confirm.

### Groom, Niagara, VSM cache pages (the three [U] items)

| Item | Verdict | Extra step |
|---|---|---|
| VSM cache pages | the flag set suffices (no residual in the VSM-on cells) | none |
| Groom components | the flag set suffices: `SetVisibility(false, true)` on the mesh propagates to the attached groom, whose proxy goes | none (a groom must be attached under the mesh, as the rule already requires) |
| Attached Niagara | the flag set suffices for rendering (proxy gone, no particles drawn) | none for rendering; the system keeps simulating (CPU) while hidden. Notify-spawned Niagara is suppressed by `bSuppressNotifyEventDispatch` (story 022) |

| Run | SetVisibility pair, game thread (mean of 120) | frame GT static / toggling every frame |

| RTX 5090 desktop, all cores | 0.0245 ms (repeat 0.0242 ms) | 10.79 / 11.01 ms (repeat 11.23 / 11.60 ms) |

The PROXY row is labelled per D56: an early-warning proxy, not 3060-class evidence; the documented 5090 -> 3060 scaling factors
do not exist yet (D56 open), so no scaled number is claimed. The render-thread side of the proxy rebuild is NOT measured
(`GRenderThreadTime` / `GGameThreadTime` sampling reads 0 for the render thread in editor PIE even with `stat unit`); a
packaged-build capture is needed for that number (story 034).

## Consequences

- Story con-022 needs no extra hide step for VSM, groom or Niagara; the ADR-0017 §6 flag set stands (no superseding ADR).
- Stories con-028 and con-034 are unblocked; con-034 owns the hardware-RT Lumen cells (an `r.RayTracing=True` build) and the
  packaged render-thread profile.
- Retained captures: one frame per state for three cells and every cell's heat image in `production/qa/spikes/2026-10-29_R5/`
  (the full 144-frame set stays local under `Saved/Harness/R5`, regenerable with the command above).
