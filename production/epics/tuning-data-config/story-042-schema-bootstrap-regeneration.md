## Context

**GDD**: `design/gdd/tuning-data-config.md`
**Requirement**: `TR-tdc-002` (requirement text lives in `docs/architecture/tr-registry.yaml`; read fresh at review time); GDD CR-3

**ADR Governing Implementation**: ADR-0004: Tuning data pipeline and validator (section 2, bootstrap guard against a regeneration deadlock)
**ADR Decision Summary**: If a generated row names a renamed or removed field, `StealthFoundation` stops compiling and the editor that hosts the commandlet cannot build. The build therefore honours `STEALTH_TUNING_SCHEMA_BOOTSTRAP=1`, set by the regeneration script only, which compiles an empty table so the editor builds, the commandlet regenerates the file and the script rebuilds without the define. `SchemaComplete` fails on an empty table, so a bootstrap build can never ship or pass CI.
**ADR Version**: 2026-10-24

**Engine**: Unreal Engine 5.8 (installed 5.8.4) | **Risk**: LOW
**Engine Notes**: No post-cutoff API. Uses UBT and the editor commandlet (story 041). The compile-time define reaching the whole Foundation module under unity build and shared PCH is the same class of claim as ADR-0007 Verification Required (1) (`PrivateDefinitions` reach every TU, [V `UEBuildModuleCPP.cs:2260-2300`]); the story's script run is the check for this define. The deferred full UBT cycles run in a disposable copy (see Test Evidence). No unverified [U] claim from ADR-0004 is touched.

**Control Manifest Rules (this layer)**:
- Required: The schema table is regenerated by the commandlet and committed with every tuning field change; `SchemaVersion` is bumped when the fingerprint changes (source: ADR-0004)
- Forbidden: Never disable, skip or reseed a failing test to pass a gate; never mark a gate Done that was never watched to fail (source: ADR-0008)
- Required: `PrivateDefinitions` reach every TU of the module under unity build and shared/private PCH (keep the CI self-test) (source: ADR-0007)
- Guardrail: Per-commit pipeline at most 10 min; this script is not a per-commit step (full UBT cycles), it is run on demand and by the nightly job if wired later (source: ADR-0008)

## Implementation Notes

*Derived from ADR-0004 section 2 and the plan amendments G2 and G4 scope notes:*

- Script: `tools/ci/regenerate-tuning-schema.ps1`. Steps: set the define, build `StealthGameEditor` Win64 Development with the empty table, run `UnrealEditor-Cmd -run=StealthTuningSchemaGen`, unset the define, rebuild, verify the regenerated file matches the renamed field. Any step failing (including the commandlet) must fail the script with a nonzero exit (spec edge: commandlet failure must fail the script; define left set must be caught).
- Define handling lives in `Source/StealthFoundation/StealthFoundation.Build.cs`: when `STEALTH_TUNING_SCHEMA_BOOTSTRAP=1`, the schema `.cpp` compiles an empty table instead of including `StealthTuningSchema.generated.inl`. How the script passes the define to UBT (for example an environment variable read by the Build.cs) is not specified by the inputs (open); whichever is chosen must be set by the regeneration script only and must invalidate the UBT action cache so the next build without it recompiles.
- A build with the define can never pass CI: this is proven by story 044 (`SchemaComplete` fails on an empty table), not re-proven here; cite that dependency in the evidence.
- Disposable copy: the script is exercised on a disposable full-project copy, never the developer's working tree. A repository exists, so the copy is a git worktree (the same rule as ADR-0008 section 7 and story 005). The renamed field in the copy is the seeded condition (the stale table references the old name).
- G2 (script stories): the plan requires a selftest under `tools/ci/**/selftest/` and an automation wrapper `StealthGame.Build.RegenerateTuningSchema` in `Source/StealthFoundation/Private/Tests/Build/`. This story's spec states the verification as a deferred full UBT cycle in a disposable copy; a wrapper running a full editor rebuild inside the very editor under test is not workable, so the content of the selftest and wrapper is not specified by qa-lead (open). Keep them to what can run without rebuilding (for example a dry-run mode that prints the planned steps and exits nonzero on a failing stubbed step) and agree the content at story-readiness; do not substitute them for the disposable-copy run.
- Prototype: none (no `Prototype:` line in the plan).

## QA Test Cases

*Written by qa-lead at story creation. The developer implements against these, do not invent new test cases during implementation.*

- **AC-1**: The regeneration script recovers from a renamed field and a define-left-set build cannot pass CI. (Verdict: ADEQUATE, DEFERRED: full UBT cycles in a disposable copy.)
  - Given: a copy where one tuning field is renamed (the stale table references the old name).
  - When: the script sets `STEALTH_TUNING_SCHEMA_BOOTSTRAP=1`, builds, runs the commandlet, rebuilds without the define.
  - Then: the script succeeds and the table matches the renamed field; a build left with the define cannot pass CI (`SchemaComplete` fails on an empty table, proven by story 044).
  - Edge cases: define left set; commandlet failure must fail the script.
