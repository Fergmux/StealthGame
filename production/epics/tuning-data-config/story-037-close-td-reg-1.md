## Context

**GDD**: `design/gdd/tuning-data-config.md`
**Requirement**: `TR-tdc-002` (requirement text lives in `docs/architecture/tr-registry.yaml`; read fresh at review time); GDD OQ-15 (TD-REG-1) and CR-15.7 (registry mirror)

**ADR Governing Implementation**: ADR-0004: Tuning data pipeline and validator
**ADR Decision Summary**: The schema is declared once and the registry, doc lint and generated table are kept in agreement mechanically, so a key cannot exist in an owner GDD without a matching registry constant and schema row.
**ADR Version**: 2026-10-24

**Engine**: Unreal Engine 5.8 (installed 5.8.4) | **Risk**: LOW
**Engine Notes**: Documentation-only story, no engine API and no unverified claim.

**Control Manifest Rules (this layer)**:
- Required: The schema table is regenerated by the commandlet and committed with every tuning field change; `SchemaVersion` is bumped when the fingerprint changes (source: ADR-0004)
- Forbidden: Never disable, skip or reseed a failing test to pass a gate; never mark a gate Done that was never watched to fail (source: ADR-0008)
- Guardrail: None specific to this story.

TD-REG-1 was opened on 2026-10-25 (`/review-all-gdds` 2026-10-25b warning W1, ruling D30): about 130 owner keys were not mirrored in `design/registry/entities.yaml`. GDD OQ-15 deferred the fix to the TDC validator work: the AC-3b doc lint is built there and the missing keys are mirrored as its first task. Story 030 mirrors the keys and story 033 builds the registry-match lint. This story is the bookkeeping step that closes the debt, and only after the lint proves it.
